# Session start

1. `git pull` (and `git branch -a` to see any open feature branches).
2. Read the top 3 entries of `notes/session-log.md`, plus `notes/backlog.md` and `notes/decisions.md`.
3. Brief Hemi in 3–5 short lines (simple English / Tanglish): last session, open branches or previews, top backlog items. Then ask what to build today.
